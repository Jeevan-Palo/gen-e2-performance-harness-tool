5. Limitations of this report

  • This run used 20 user(s). The requirements apply at 50 users, so they are reported as not measured at peak load.
  • The load tool and the application ran on the same machine, so they competed for CPU and the timings are not representative of a separate production setup.
  • CPU and memory come from Docker's own statistics (sampled every few seconds); treat them as indicative, not exact host usage.
  • The load model and the targets are assumptions of the test lead, not figures agreed with a business owner.
  • Environment check: 7 catalogue calls returned 200 on the local copy via curl; status codes only, response shapes not compared.
